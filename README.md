# PlusEV Web

Next-generation software solutions for forward-thinking businesses.

## Tech Stack

- **Framework**: Next.js 15+ (App Router)
- **Styling**: Tailwind CSS v4 (Modern, CSS-only config)
- **Animations**: Framer Motion
- **CMS**: Sanity (Ready for integration)
- **Icons**: Lucide React

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Open the browser**:
   Go to [http://localhost:3000](http://localhost:3000)

## Structure

The site follows a high-impact 3-block structure:
1. **Hero**: Value proposition and primary call-to-action.
2. **Process**: 3-pillar description of our expertise (Discovery, Dev, Deployment).
3. **Conversion**: Trust signals and contact form.

## Deployment

Build the project:
```bash
npm run build
```
